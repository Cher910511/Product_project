# 项目名称：Awesome Notes
## 项目名称：Awesome Notes App

## 📝 项目简介

Awesome Notes App 是一个简洁高效的笔记管理应用，支持多端同步，助你轻松记录灵感、待办事项和工作笔记。

## 🚀 功能特点

- ✍️ 支持 Markdown 格式编辑
- 🌙 黑暗模式切换
- 🔍 笔记全文搜索
- ☁️ 云端同步（支持 GitHub）
- 🔐 私密笔记加密存储
